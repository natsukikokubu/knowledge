### クラスとは何か
 - クラスはオブジェクトを作成するためのテンプレート
 - データをカプセル化する
   - JSのクラスはプロトタイプに基づいて構築されている
     - JSが持っている構成要素はオブジェクトだけ
     - {}の中にクラス本体を記述する


同じプロパティやメソッドを持つオブジェクトの設計図となるもの

classを宣言してその中にメソッドを定義するとオブジェクト(インスタンス)で使用することができる

class MyClass {
constructor() {
// コンストラクタ: インスタンスを作成する際に実行されるメソッド
// インスタンス固有の初期化処理を行う
}
method1() {
// メソッド1の定義
}
method2() {
// メソッド2の定義
}
}
