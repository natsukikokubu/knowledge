## 再宣言について
  - 再宣言とは変数を同じ変数名で再度宣言すること
  - デメリットとして意図しない動作が発生する可能性があるため避けるのが良い
  - バグの原因になる

## Var,let,constそれぞれについて
  - var: 再代入再宣言可能、関数スコープ/ ifやforなどのブロックで宣言してもブロック外でも変数が参照できてしまう
  - let: 再代入可能、再宣言不可能、ブロックスコープ/ 同じ名前の編数を再宣言できない
  - const: 再代入再宣言不可能、ブロックスコープ/ 値が変化する可能性がある場合には使用できないため使い所を考える必要がある

## 結局どう使い分けたらいいのか
  - varはブロックスコープにできない、再代入も再宣言も防げないため基本使用しない
  - 基本はconstで宣言する
  - 再代入が必要そうなときにだけletを使用する

## テンプレートリテラルについて
  - +演算子を用いた文字列結合を必要とせず、変数や関数の戻り値、式などを文字列内に展開できる
  - 基本的には文字列を使用して変数の埋め込みや改行を含んだ文字列を扱いたいときに使用する
  - テンプレートリテラル内の改行やスペースもそのまま出力されるため複数行の文字列を定義することができる


## Mathのデータ型
  - Mathはオブジェクト(数値処理を行うための関数や定数を備えた)
  - Mathはnumber型で動作する・BigInt型では動作しない
  - Mathのプロパティ = Math.PI(円周率)
  - Mathのメソッド = Math.floor()、Math.max()、Math.random()、etc.

## プロパティとメソッドの違い
  - プロパティ
  - オブジェクト指向プログラミングにおけるオブジェクトの属性や状態を表す要素
  - ex.車がオブジェクトだとすると、車の色、ブランド、など
  - オブジェクトがプログラム内でどのように振る舞うかの定義をするのに役立つ

  - メソッド
  - オブジェクトが取りうるアクションや振る舞いを実装したもの
  - 特定のタスクを実行するためのコードの集まり
      - ex.setTimeout()、console.log()、Math.random()、など

## setTimeout()
  - windowオブジェクトのメソッド
  - 一定時間後に指定した関数を実行する
  - setTimeout(実行したい関数, 実行までの時間(ミリ秒))  で指定する


## 標準関数/組み込みオブジェクト
  - プログラミング言語にあらかじめ用意されている関数のこと
  - ex.console、Math


## コールバック関数
  - 関数に引数として渡されていて関数内から呼び出される関数
  - コールバック関数は非同期処理を行うときに使用される


## 引数に関数を入れるメリット
  - forEachやmapなど配列の各要素に対して実行する処理を引数で指定できる
  - イベントや非同期処理など、非同期な処理の完了後に実行する関数を引数として渡すことで
処理が完了したタイミングで適切に呼び出せる

## numbers(配列)のデータ型は何か
  - numbersのデータ型は配列型
  - 配列型は複数の値をまとめて扱うためのデータ型
  - typeof演算子でデータ型を調べるとobjectが返ってくる
  - typeof 演算子は、プリミティブ型以外のデータ（オブジェクト）に対しては常に "object" を返す仕様になっている

## どの順番で実行されているか
; let numbers = [];
; for (let i = 0 i < 100; i++) {
;   numbers.push(i);
; }
  - 実行される順番
    - 初期値iに0が代入①
    - iが100未満である判定がされる②
    - numbersにiが追加される③
    - iに1が加算される④
    - iが100未満である判定がされる②
    - numbersにiが追加される③
    - iに1が加算される④
    - ・・・i < 100がfalseになるまで繰り返される

## 論理演算子とは
命題や集合などの論理演算をするためのもの
if文の条件判定によく使用するもの真(true)または偽(false)を判定することができる
例えば
- A && B の場合 AND演算 AかつB
- A || B の場合 OR演算 AまたはB
- !A の場合 NOT演算 A以外ならなんでもOK

### 論理積&&
オペランドを左から右に向けて評価して遭遇した最初の偽値のオペランドをただちに返す
全ての値が真値の場合は最後のオペランドを返す
- falseに変換される値
   - false
   - null
   - NaN
   - 0
   - 空文字列 ("" または '' または ``)
   - undefined

### 論理和||
論理和 (||) 演算子 (論理的分割) をオペランドの組み合わせに対して使用すると、オペランドのうち 1 つ以上が true である場合に true になります。一般的には論理値（ブール値）で使用されます。その場合は論理値を返します。ただし || 演算子は実際には指定されたオペランドのうち一つの値を返すので、この演算子が論理値以外で使用された場合は、論理値以外の値を返すことになります。
- falseに変換される値
  - null
  - NaN
  - 0
  - 空文字列 ("" または '' または ``)
  - undefined
