## useStateとは
  - 関数コンポーネントでstateを管理(stateの保持と更新)をするためのフック
  - stateとはコンポーネント内部で保持する状態のことで画面上に表示されるデータやアプリケーションが保持している状態のこと

const [状態変数, 状態を変更するための関数] = useState(状態の初期値);
const [count, setCount] = useState(initialState)

ちなみにクラスコンポーネントでは、、、
this.state = {
  count: initialState
}
  - 再レンダリング後もReactはその変数の現在のstateを保持しており、最新のstateの値を関数に渡す
  - 現在のstateを更新したい場合は、setStateを呼ぶ
  - stateが更新されると再レンダリングが実行される


## useEffectとは
  - useEffect(() => {
  /* 第1引数には実行させたい副作用関数を記述*/
  console.log('副作用関数が実行されました！')
},[依存する変数の配列]) // 第2引数には副作用関数の実行タイミングを制御する依存データを記述

  - 第二引数指定なしの場合、render毎に第一引数の関数を実行
  - 空の配列が渡された場合、最初のrender時のみ第一引数の関数が実行される
  - 値の配列が渡された場合、最初のマウント時と与えられた値に変化があった場合のみ第一引数の関数を実行する


## useCallbackとは
  - useCallbackはパフォーマンス向上のためのフックで、メモ化したコールバック関数を返す
  ### メモ化とは
      - 同じ結果を返す処理について初回のみ処理を実行記録しておき、値が必要となった2回目以降は、前回の処理結果を計算することなく呼び出し値を得られるようにすること
      - イベントハンドラーのようなcallback関数をメモ化し、不要に生成される関数インスタンスの作成を抑制、再描画を減らすことにより、都度計算をしなくても良くなることからパフォーマンスの向上が期待できる
  - 第一引数にはコールバック関数、第二引数には依存する値の配列を渡す
  - 第二引数に渡された値が変更された場合のみ、第一引数の関数が実行される
  - useCallbackは、コールバック関数のインスタンスを再生成することなく、再利用することができる
  - useCallbackは、コールバック関数の再生成を抑制することで、再レンダリング時に不要な関数の生成を防ぐことができる


## useMemoとは
  - useMemoはパフォーマンス向上のためのフックで、メモ化した値を返す
  - 第一引数には値を返す関数、第二引数には依存する値の配列を渡す
  - 第二引数に渡された値が変更された場合のみ、第一引数の関数が実行される
  - メモ化された値は再レンダリング時に再計算されることなく、前回の値を返すことができる
  - useMemoは、計算コストの高い関数の結果をメモ化することで、再計算を防ぐことができる


## e.preventDefault()とは
  - イベントのデフォルトの動作をキャンセルするためのメソッド
  - イベントが発生した要素のデフォルトの動作をキャンセルすることができる
  - 例えば、フォームの送信ボタンをクリックした際にページがリロードされるのを防ぐことができる
  - イベントのデフォルトの動作をキャンセルすることで、イベントの伝播を止めることができる
  - イベントの伝播を止めることで、イベントが親要素に伝播されるのを防ぐことができる


## findメソッドとは
  - find()はArrayインスタンスのメソッドで提供された関数を満たす配列内の最初の要素を返す
  - 引数は配列に対して実行する関数で、この関数は配列の各要素に対して実行される
  - 要素が見つからなかったらundefinedを返す
find(callbackFn)
find(callbackFn, thisArg)


## Patchメソッドとは
  - PATCHメソッドは、リソースの一部を更新するために使用されるHTTPメソッド
  - PUTメソッドと同様にリソースを更新するために使用されるが、PUTメソッドはリソース全体を更新するのに対して、PATCHメソッドはリソースの一部を更新するために使用される


## SPAとMPAの違い = HTMLファイルの数
  - SPA:シングルページアプリケーション
    - 単一のHTMLファイルで構成されている
    - 初回のみHTMLファイルをサーバーからもらう
    - HTMLファイルの中身とURLをJSで書き換えることでページ遷移しているように見せる

  - MPA:マルチページアプリケーション
    - 複数のHTMLファイルで構成されている
    - 新しページに移動をするたびにサーバーにリクエストを送信するため画面更新のリロードが発生する


## SPAのメリットデメリット
  - メリット
    - ページの再読み込みが発生しない = ページ遷移が高速で行うことができる
  - デメリット
    - 初回の読み込み時間の増量(JSファイルが大きい)
    - メモリ使用量の増加(クライアントサイドで担う処理が多いためユーザーのPCスペックやネットワーク環境の影響を受けやすい)
